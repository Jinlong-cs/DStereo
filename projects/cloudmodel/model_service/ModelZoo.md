# version node

## v0.6.X

此版本模型为 aidi model card 初版。功能上可以支持用户使用 aidi模型仓库的内容在本地完成模型推理。注意，此版本的模型不保证aidi云端推理的方式可以运行。

## v0.7.X

- 新增分类任务、增加全球标志牌检测模型
- 支持模型AIDI 服务化部署
- CloudModelInference 支持服务化部署推理
