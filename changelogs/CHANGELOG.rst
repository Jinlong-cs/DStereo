Changelog
---------

All notable changes to this project will be documented in this file.

The format is based on `Keep a Changelog <http://keepachangelog.com/en/1.0.0/>`_ .

All changelogs are divided into the following parts according to modules.

.. toctree::

   DATA.md
   MODEL.md
   ENGINE.md
   CALLBACK.md
   METRIC.md
   TOOL.md
   UTIL.md


It is recommended to modify the directory and changelog correspondence as follows:

+---------------------------------------------------+------------------------------------+
| directory                                         | changelog                          |
+===================================================+====================================+
| hat/models                                        | MODEL.md                           |
+---------------------------------------------------+------------------------------------+
| hat/callbacks && hat/profiler                     | CALLBACK.md                        |
+---------------------------------------------------+------------------------------------+
| hat/data                                          | DATA.md                            |
+---------------------------------------------------+------------------------------------+
| hat/engine && hat/optimizers                      | ENGINE.md                          |
+---------------------------------------------------+------------------------------------+
| hat/metrics && hat/evaluation && hat/visualize    | METRIC.md                          |
+---------------------------------------------------+------------------------------------+
| hat/core && hat/utils && examples                 | UTIL.md                            |
+---------------------------------------------------+------------------------------------+
| tools && plugins && docs                          | TOOL.md                            |
+---------------------------------------------------+------------------------------------+
| projects/${project}                               | projects\/${project}\/CHANGELOG.md |
+---------------------------------------------------+------------------------------------+
