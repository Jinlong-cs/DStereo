
感知算法生产流程简介
===========================================================

下面对Pilot周视算法的生产流程进行依次介绍。


数据准备
------------------------------------------

为获取训练模型需要的数据，用户需要先进行数据准备，标准过程包含数据筛选、数据送标、数据打包，本代码包中包含的只有数据打包过程。
数据打包就是将标注好的数据转化成训练需要使用的格式。
数据打包具体的介绍可以参考 :ref:`pilot-data-preperation` 。


模型训练
------------------------------------------

通过准备好的数据训练模型，使得模型在相应任务上能够有预期内的输出结果。
具体的训练操作用户可以参考：:ref:`train-operations-of-multitask`。

模型预测
------------------------------------------

模型训练完成后，我们可以通过给模型输入一个原始数据（如图像）来得到模型的输出结果，并根据结果来判断训练过程是否正常，常见的方法是对模型输出做可视化展示。
本算法包提供了模型可视化展示的操作方法，用户可以参考：:ref:`infer-operations-of-multitask`。


模型评测
------------------------------------------

尽管模型的可视化展示可以帮助用户定性观察模型的表现，但是为了更准确评价模型的效果，需要使用评测工具对
模型进行定量评测，得到模型各类任务的定量指标。
具体的评测操作，用户可以参考：:ref:`eval-operations-of-multitask`。


模型编译与发布
------------------------------------------

当模型指标满足部署要求，用户就可以对模型进行编译，为最终将模型部署上板做准备。
用户可以参考 :ref:`hat-pilot-model-compile` 来进行模型的编译操作。
