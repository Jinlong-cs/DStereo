模型训练架构
==================================

本章介绍Pilot感知算法中的模型训练架构。

.. note::
  首先，请您参考文档中的 :ref:`hat-framework` 章节，了解 ``HAT`` 中模型训练的执行方式。
  此外，也请您按需阅读 :ref:`hat-quantization` 中的内容，以了解量化训练的相关细节。

正如 :ref:`pilot-model-structure` 所介绍的，整个Pilot感知算法方案中包含几种多任务模型和图像质量单任务模型。
考虑到单任务模型训练较为简单，在此我们重点关注多任务模型的训练方式。

多任务模型的搭建
-------------------

整体框架请参考 :ref:`hat-graph-model`，而具体的实现则会在 :ref:`pilot-config-intro` 中加以详细解析。

总而言之，各任务需要独立搭建自己的模型结构，过程中需要声明某些模块的共享关系。然后再通过对部分共享模块的合并，搭建出任务模型。

多任务模型的训练方法
----------------------------

整体的训练策略是每个任务分开来做训练，分别更新参数，直到所有任务都收敛。

实现上，则正如 :ref:`hat-graph-model` 中所介绍的，主要利用了 :py:class:`~hat.models.structures.multitask_graph_model.MultitaskGraphModel` 开放出的使用部分任务对应的子模型结构做forward-backward的能力。
只要在提供训练数据的同时，给出数据对应的任务信息，就能做到只训练相应任务并更新相关参数。
